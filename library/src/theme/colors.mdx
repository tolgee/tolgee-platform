# Colors

Read from the theme itself, so this always matches what the app renders. Switch Light and Dark in
the toolbar — every value updates with it, and tokens that differ between the two modes show the
other mode's value underneath.

The values come from `figmaTheme.ts`, which is exported from the Figma design system and must not
be edited by hand.

## Brand

Raw palette exported from Figma, available as `theme.palette.colors`. These do not change with the
mode.

<Swatches path="palette.colors" />

## Semantic tokens

Available as `theme.palette.tokens`. These are what components should reach for — they follow the
mode, the brand palette above does not.
