# Colors

Every value on this page is read from the library theme at render time, so it cannot drift from
`getTheme`. Switch Light and Dark in the toolbar — every value updates with it, and tokens that
differ between the two modes show the other mode's value underneath.

**Brand** and **Semantic tokens** are exported from Figma; everything below them is hand-maintained.
See **Foundations → Theme** for which file to edit and where a fresh Figma export goes.

## Brand

Raw palette exported from Figma, available as `theme.palette.colors`. These do not change with the
mode.

{COLOR_SECTIONS.brand.map((group) => <Swatches key={group} group={group} />)}

## Semantic tokens

Available as `theme.palette.tokens`. These are what components should reach for — they follow the
mode, the brand palette above does not.
