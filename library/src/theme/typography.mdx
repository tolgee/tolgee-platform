# Typography

Rendered at the size and weight the theme actually assigns, not described in a table.

The base family is the system font stack, so text matches the operating system the app runs on.
No web font is loaded for body text — Righteous and Rubik exist only for the logo wordmark and
live in the webapp, not in this library.
