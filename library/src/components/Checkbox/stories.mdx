# Checkbox

<Upstream docs="react-checkbox" />

**Tolgee uses the checkbox in exactly two ways.** This page documents those two and nothing else —
Material UI offers more, and the extra options are not choices we make.

A checkbox is a value you are setting, and it is submitted or applied with the rest of the form. A
setting that takes effect the moment you click it is a **Switch**; one of several options where only
one may win is a **Radio**.

## 1. In a list — the common one

<Canvas of={CheckboxStories.InAList} />

Selecting rows: keys in Translations, entries in Translation memory, terms in the glossary,
languages in a filter. `size="small"`, standing alone, with the row's own text beside it. **32 of
the 59 checkboxes in the product are this.**

The reference is `views/projects/translations/CellKey.tsx` — the checkbox beside a key:

```
<Checkbox
  size="small"
  checked={isSelected}
  onChange={handleToggleSelect}
  onClick={stopBubble()}
  data-cy="translations-row-checkbox"
/>
```

`stopBubble()` is there because the whole cell is clickable — without it, ticking the box also opens
the key.

The header checkbox above the list is the same control with `indeterminate`, which is the state for
"some but not all".

## 2. In a form — beside its own label

<Canvas of={CheckboxStories.InAForm} />

Options in a dialog: what to include in an export, what a glossary term is, which automatic
translation to switch on. **Default size, inside `FormControlLabel`** — 17 call sites.

```
<FormControlLabel
  control={<Checkbox checked={value} onChange={toggle} />}
  label={t('project_languages_enable_for_import')}
/>
```

## One size, and one that nobody chose

<Canvas of={CheckboxStories.TheTwoSizes} />

`size="small"` is written **39 times**. `size="medium"` is written **zero times** — in the whole of
`webapp/src`, for `Checkbox`, `Switch`, `Select` and `Radio` alike. The 20 checkboxes that come out
at Material UI's 24px do not ask for it; they simply say nothing, and 24px is what Material UI gives
you when you say nothing.

| What the prop says | Call sites |
| ------------------ | ---------- |
| `size="small"`     | **39**     |
| `size="medium"`    | **0**      |
| no size prop       | 20         |

So the product does not have two sizes on purpose. **It has one size and a gap**, and where the two
meet you can see it — see Findings.

<Callout title="The standard is small" kind="warning">
  20px is the size 39 call sites deliberately asked for, and it is the one in
  Translations. The theme has no `MuiCheckbox` entry at all, so nothing makes it
  the default and every caller has to remember. Setting
  `defaultProps: { size: 'small' }` in the theme would make it true everywhere
  and let the 39 props go.
</Callout>

## What it is made of

Measured in your browser as this page renders. **These are the sizes the checkbox is meant to
have** — this Storybook is the specification, so it renders with `htmlFontSize: 16`, which is what
the document root actually is.

<Spec>
  <Checkbox size="small" defaultChecked />
</Spec>

<Spec>
  <Checkbox defaultChecked />
</Spec>

| Size    | Glyph | Padding | Control  |
| ------- | ----- | ------- | -------- |
| `small` | 20px  | 9px     | **38px** |
| default | 24px  | 9px     | **42px** |

The padding is **hit area** — the box you can click is nearly twice the box you can see, which is
what makes a checkbox usable in a dense row. It is 9px either way, so the two sizes differ only by
the glyph.

<Callout title="The app does not render these numbers yet" kind="warning">
  Where a `(app: …)` appears above, the product currently renders something
  else: the theme it ships declares a rem to be 15px while the root is 16, so
  every size Material UI derives lands 6.7% high — 39.33px instead of 38. One
  line fixes it, and **General Findings** has the measurements and the order to
  do it in.
</Callout>

## Before you write a component

The product already has these. Reach for one before building another:

| It exists                     | For                                           |
| ----------------------------- | --------------------------------------------- |
| `common/form/fields/Checkbox` | a checkbox bound to formik                    |
| `SelectAllCheckbox`           | the header box over a selectable list         |
| `MultiselectItem`             | a checkbox row inside a menu or search select |
| `FilterItem`                  | a filter row, with include and exclude        |
| `LoadingCheckboxWithSkeleton` | a checkbox whose value is still loading       |
| `CharLimitCheckbox`           | the character-limit option on a key           |
| `PluralFormCheckbox`          | the plural option on a key                    |

<Callout
  title="If you are about to write your own, check this list first"
  kind="warning"
>
  Seven of these already exist and several were written more than once. A new
  checkbox component is worth writing when the behavior is genuinely new — not
  when the difference is a size, a margin or a label position.
</Callout>

## States

<Canvas of={CheckboxStories.States} />

`indeterminate` is the header state for a partly-selected list. `disabled` keeps the value visible
while explaining you cannot change it.

## Don't

- **Don't set a color.** All 59 leave it alone and the theme decides.
- **Don't pick the size by eye.** Row means `small`, `FormControlLabel` means default.
- **Don't put words beside it without `FormControlLabel`** — see **Labels**.
- **Don't hand-size it with `sx`.** Two call sites do; the size prop exists.

## Where the styling lives

Nowhere of ours. `getTheme.ts` has no `MuiCheckbox` entry, so the box is Material UI's at Material
UI's colors. See **Foundations → Component styles**.
