# Illustrations

Drawings that are not icons. They carry their own size and composition, appear once on a screen, and
are never interchangeable with a glyph — an empty state, a placeholder, art that sets a tone.

```
import { GlossaryEmpty } from '@tginternal/library/illustrations';
```

## Illustration or icon?

The boundary is measurable, so it does not have to be argued about:

- **viewBox up to 24×24, takes its color from the surrounding text** — an icon. It goes to
  `library/src/icons/custom` and gets a meaning on **Foundations → Icons**.
- **larger, with its own intrinsic size** — an illustration. It goes here.

Anything on the Icons page that breaks the first rule is flagged there, so the two cannot quietly
mix.

it belongs — an illustration is documented by the screen it serves, not by a meaning it carries.
